# NVIDIA Financial Performance Dashboard

## Overview

Power BI dashboard analyzing NVIDIA's financial performance using annual financial statements.

## Features

- Executive Summary Dashboard
- Revenue & Growth Analysis
- Profitability Analysis
- Balance Sheet Analysis
- Financial Ratio Analysis

## Tools Used

- Power BI
- DAX
- Data Modeling
- Financial Analysis
