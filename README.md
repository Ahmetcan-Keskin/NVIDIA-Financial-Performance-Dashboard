# NVIDIA Financial Performance Dashboard

## Overview

Power BI dashboard analyzing NVIDIA's financial performance using annual financial statements.

## Features

- Executive Summary Dashboard
- Revenue & Growth Analysis
- Profitability Analysis
- Balance Sheet Analysis
- Financial Ratio Analysis
  
 ## Key Highlights

- Built with Power BI and DAX
- Designed a star schema data model
- Created financial KPIs and ratio analysis
- Developed interactive dashboards with yearly filtering
- Analyzed revenue, profitability, and financial health indicators

## Tools Used

- Power BI
- DAX
- Data Modeling
- Financial Analysis
